# Genesis: Patches

Fixes and clean-up for the Genesis Mod Pack and its Combat Extended edition. It fixes small conflicts between mods in the pack, makes the fourth and fifth mouse buttons work again as Letter Stack Cleaner's key on 1.7, hides the "Need research bench" alert until you have unlocked a research bench, and hides a few known, harmless startup errors from other mods while their authors work on fixes, noting each one in the log as an info line instead.
